## Draft GitHub release body

<!-- release-body:start -->
Maintenance release addressing the CRAN check failure introduced by the
deprecation of `future::supportsMulticore()`. Requires R 4.2 or newer.

- Use `parallelly::supportsMulticore()` directly, avoiding deprecation warnings
  and test failures with parallelly 1.50.0. Thanks to Henrik Bengtsson for
  identifying the issue and contributing [PR #264](https://github.com/jakeberv/bifrost/pull/264).
- Clarify the fixed-order greedy search, numerical-stability guidance,
  rate-map diagnostics and fit weighting, and worked examples. Update the
  jaw-shape correlation heatmap to match the manuscript's color scale.
- Filter excluded local files before devtools builds so experiment outputs
  and Git history do not become part of the initial build copy.

The search algorithm and initialization defaults are unchanged from 0.2.2.
High-dimensional fits remain sensitive to initialization and random state;
some intermediate proposals can fail to converge ([#242](https://github.com/jakeberv/bifrost/issues/242)).
The existing Gumbel KL-divergence bootstrap can understate uncertainty because
of overflow/underflow; its correction remains deferred ([#231](https://github.com/jakeberv/bifrost/issues/231)).

Version 0.2.3 is [available on CRAN](https://CRAN.R-project.org/package=bifrost).
See the [changelog](https://jakeberv.com/bifrost/news/index.html) and
[release-status page](https://jakeberv.com/bifrost/articles/development-status.html).
<!-- release-body:end -->

## Latest check: normal devtools build configuration

`Config/build/copy-method: copy` makes pkgbuild select package files using the
existing exclusions before invoking `R CMD build`. This lets normal
`devtools::submit_cran()` calls from the repository root avoid copying local
experiment output and Git history. The experiments remain in place.

An ordinary `pkgbuild::build(path = ".", manual = TRUE)` completed in 2.054
seconds with this setting. The resulting archive passed
`R CMD check --as-cran --run-donttest`, including PDF and HTML manuals:
**0 errors, 0 warnings, 0 notes**. Tests reported 2,980 passing expectations,
zero failures or warnings, and 138 skips.

The archive's SHA-256 is
`6f46bd3ef19aa983984902ab3f66983084417b0aa91a02e9ab827819197ab283`.
The exact archive, check log, and test output are preserved in
`output/cran-release-0.2.3-build-config.Bbn63IDx/`.
The only source-file difference from the earlier checked archive is
`DESCRIPTION`; implementation, tests, README, and help files match. This archive
